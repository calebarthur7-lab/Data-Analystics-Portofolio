## 🚀 Projet mis en avant

### 📊 Analyse des ventes & pilotage des stocks — Power BI

Projet de Business Intelligence conçu pour transformer des données de **ventes, d’inventaire et de satisfaction client** en un outil de pilotage.

Le dashboard comprend notamment :

- une **Vue Direction** avec KPI commerciaux ;
- une analyse du **chiffre d’affaires par catégorie** ;
- une analyse de l’**évolution mensuelle du CA** ;
- une **Vue Alerte Stock** ;
- l’identification des **produits en stock critique** ;
- un modèle sémantique reliant ventes, inventaire, avis clients et calendrier.

**Technologies :** Power BI · Power Query · DAX · Data Modeling · Data Visualization
